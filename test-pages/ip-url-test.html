TC04 — IP ADDRESS HOSTNAME TEST

IP Address Hostname Indicator Test

This page documents and tests IP address hostname indicator recognition in AI Phishing Guard.

Rule Explanation

Phishing attackers frequently host malicious forms directly on IP addresses (e.g. http://192.168.1.100/verify) to bypass domain registration and DNS domain reputation controls.

Expected Indicator: URL uses an IP address instead of a domain (+30)
